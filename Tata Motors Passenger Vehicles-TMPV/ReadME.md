## 3 Statement Financial Model and Analysis
- Built a fully integrated, dynamic 3-statement financial model (Income Statement, Balance Sheet, Cash Flow) for Tata Motors Passenger Vehicles (TMPV), with financial forecasts and Financial Ratio Analysis covering profitability, returns (ROE/ROCE), liquidity, and working capital efficiency.
•	Developed the model as a template to run on any Indian listed company from raw inputs alone, with Sales, EBITDA, and EPS forecasts generated via trend regression, allowing fast, repeatable company analysis.
