# Financial Modelling & Analysis
- Built a fully integrated, dynamic 3-statement financial model (Income Statement, Balance Sheet, Cash Flow) for Indian listed companies, with a built-in balance check and 20+ ratios covering profitability, returns, liquidity, and working capital efficiency.
- Developed the model as a template to run on any Indian listed company from raw inputs alone, with Sales, EBITDA, and EPS forecasts generated via trend regression, allowing fast, repeatable company analysis.
